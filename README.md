# dsh-fisher · 摸鱼海岸

**简体中文** | [English](README.en.md)

面向 DeepSeek Harness（DSH）Web 的休闲钓鱼与收藏插件。走到海边，慢慢钓一竿；也可以开启自动钓鱼，让角色在你使用 DSH 时留在岸边等鱼。

**当前主线：`main` · `0.2.0-preview.6`**。提供四处可行走的 3D 海岸、精细 2D 人物与像素纸面界面，支持从源码构建并本地安装，尚未发布到 npm。

原像素版 `0.1.0-rc.11` 完整保存在 [archive/pixel-v1-rc11](https://github.com/Nath-Vikky/dsh-fisher/tree/archive/pixel-v1-rc11)。

## 可以做什么

- **在四处海岸散步与钓鱼**：摸鱼塘、热梗湾、月光池、深潜海各有不同地形与建筑，每处海岸提供两处交互钓点。使用摇杆、方向键／WASD 或导航按钮移动。
- **手动钓鱼或随工作自动钓鱼**：抛竿、提竿、控制收线张力；自动模式随 DSH 活动累计进度，稀有收获等待更久，可随时接管这一竿。
- **收集 49 个图鉴条目**：28 种鱼、13 种奇珍异兽、4 件遗物、4 位来客；其中 37 种生物具有原色、珠光和星砂外观，并保留尺寸纪录。
- **升级装备与探索**：14 件鱼具、8 类鱼饵、潮相选择，以及随手册等级和研究进度解锁的海岸。普通面团免费无限。
- **认识来客、完成委托**：12 种委托、24 项成就、来客邀请与故事，每位来客两套衣装。交流采用双侧原版半身立绘，主角与来客轮流说话。
- **布置收藏**：鱼缸、陈列架、24 件装饰与七种收获卡样式；收获卡可导出为本地 PNG。背包支持分类、分页、锁定与批量整理。
- **按习惯调整窗口**：悬浮入口可自由拖动，游戏窗口支持缩放、停靠与尺寸记忆；可调整主题、字号、动态效果、画布开销和声音。

人物采用带体积明暗的 2D 图像，保留站立、眨眼、正背面行走、抛竿、持竿、收线和收获反应，并参与 3D 场景遮挡。主角远离镜头时会转为背面。

## 开始游玩

当前游戏界面为中文；英文说明保留对应的中文按钮名，便于查找。

### 手动钓鱼

1. 点击页面上的“摸鱼海岸”入口，拖动右下方摇杆走向水边；也可点击“去哪里”自动前往钓点。
2. 靠近钓点后，点击左侧“在这里钓鱼”，再点击“抛竿”。同一海岸的两处钓点共用该地区的鱼池与装备。
3. 浮漂提示咬钩后点击“提竿”，按住收线按钮，张力升高时松开。辅助松线默认开启，也可选择“点击切换收线”。
4. 收获弹窗出现后，点击空白处或“留下并继续”收入背包，也可出售、放流或回收。背包满时需要先处理收获。

方向键／WASD 需要先聚焦场景或摇杆。手动钓鱼时，收起窗口、离开页面或点击游戏外部会暂停；回来后点击“继续这一竿”。

### 自动钓鱼

在右侧“托管”中开启“自动钓鱼”，角色会走回所选钓点，沿用当前鱼饵和装备，随 DSH 的模型响应与工具活动累计钓鱼进度。收获自动进入背包或图鉴，返回海岸时可查看汇总；背包满或鱼饵不足时暂停。

点击“接管这一竿”即可切回手动操作，保留这次收获与已累计进度。自动钓鱼默认关闭，与工作补给独立；收起海岸小窗仍可进行，退出 DSH 或停止有效活动后不会累计离线时间。

### 菜单与来客

| 入口 | 用途 |
| --- | --- |
| 图鉴 | 查看发现、外观、尺寸纪录与线索 |
| 背包 | 查看收获，锁定个体，出售、放流或整理 |
| 码头 | 切换海岸、鱼饵、装备与潮相，管理本机存档 |
| 手记 | 接取委托、查看成就，认识来客，布置与展示收藏 |
| 托管 | 开关自动钓鱼、查看进度与汇总、接管当前一竿 |
| 设置 | 调整窗口、主题、字号、动态效果、画面开销与声音 |

靠近来客点击“交谈”，或从来客手记点击“聊一句”，即可打开双侧立绘对话。点击“再聊一句”和“继续”推进交流，按 Esc 或“结束交谈”返回；闲聊不消耗物品或改变关系进度。

悬浮入口默认显示鲸汐半身像与流水，自动钓鱼时改为钓竿入水图标。入口与窗口位置都会保留；DSH 设置中的“摸鱼海岸”分栏也提供插件启停开关。

## 构建与安装

当前适配 **DSH Web `0.1.2-rc.1`**。构建使用 **Node.js `22.20.0`**、**pnpm `11.19.0`**；以下命令适用于 Windows PowerShell。3D 场景需要浏览器支持 WebGL，无法加载时可切回轻量画面。

获取主线并构建安装包：

```powershell
git clone https://github.com/Nath-Vikky/dsh-fisher.git
cd dsh-fisher
pnpm install --frozen-lockfile --ignore-scripts
pnpm check
pnpm pack
```

在独立目录安装并启动预览：

```powershell
$env:DSH_HOME = Join-Path $PWD 'tmp/dsh-fisher-preview'
$fisherVersion = (Get-Content .\package.json -Raw | ConvertFrom-Json).version
$fisherPackage = Join-Path $PWD "nath-vikky-dsh-fisher-$fisherVersion.tgz"
pnpm dlx @deepseek-ai/dsh@0.1.2-rc.1 plugin --profile web add --ignore-scripts $fisherPackage
pnpm dlx @deepseek-ai/dsh@0.1.2-rc.1 web
```

打开终端提供的本地地址，点击“摸鱼海岸”即可游玩。钓鱼本身无需模型 API Key；自动钓鱼需要 DSH 中有实际活动。

更新已有安装时，先停止对应 DSH 宿主，在同一个 `DSH_HOME` 中移除旧插件，再用新构建的包重新安装并启动。移除插件默认保留存档。

```powershell
pnpm dlx @deepseek-ai/dsh@0.1.2-rc.1 plugin --profile web remove @nath-vikky/dsh-fisher
```

开发时可另外运行：

```powershell
pnpm test
pnpm content:check
```

## 存档与隐私

游戏进度与插件启停状态保存在宿主 `$DSH_HOME/fishersave/`；未设置 `DSH_HOME` 时使用用户目录下的 `.dsh/fishersave/`。窗口与入口位置偏好保存在当前浏览器。

“码头 → 本机存档”提供导出、导入预览、备份恢复和删除。导入确认后替换当前进度，并保留替换前的恢复文件；自动钓鱼与工作补给恢复为关闭。删除需要输入“删除摸鱼海岸”，只清理本插件的游戏数据及其备份。

旧版存档升级时会保留原文件，已有个体、余额与纪录继续有效；建议更新前导出一份。保存失败时会暂停并提示重试，突然断电可能回退最后一段尚未保存的操作。

**插件不新增模型请求，不读取聊天正文、思考正文、工具参数或 Token 数量。** 自动钓鱼和工作补给仅使用 DSH 的活动元数据；没有充值、交易、联机或排行榜。

## 性能与兼容性

游戏与 3D 程序按需加载，并使用压缩传输和版本缓存。人物动作提前解码、分批上传纹理，场景完成首帧准备后再显示；短暂收起窗口或切换码头可复用已解码图片，当前来客的原版立绘也会提前准备。

默认最高 30 FPS；设置中的“降低动画与画布开销”将上限降为 20 FPS，降低渲染分辨率并关闭实时阴影。页面不可见、离焦或打开详情时暂停渲染；离开场景释放显存，闲置图片缓存自动释放。

当前为预览版，实际流畅度取决于设备与 DSH 负载。窗口是 DSH 网页内的浮层；WebGL 不可用时可重试或使用轻量像素画面。其他 DSH 版本和平台尚未完成兼容性验证。
